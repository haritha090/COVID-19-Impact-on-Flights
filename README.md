# #✈️ COVID-19 Impact on Flights – Data Analysis Project

## 📌 Overview
The COVID-19 pandemic caused unprecedented disruption to the global aviation industry, significantly reducing flight operations, passenger traffic, and airline revenues.  

This project analyzes real-world COVID-19 and flight datasets to understand how the pandemic impacted global air travel. The focus is on data cleaning, validation, exploratory analysis, and generating actionable insights through visualization.

---

## 🎯 Project Objectives
- Analyze the impact of COVID-19 on global flight operations  
- Identify trends before, during, and after peak pandemic periods  
- Perform data cleaning and validation to ensure data integrity  
- Conduct exploratory data analysis (EDA)  
- Visualize patterns and correlations between COVID cases and flight frequency  

---

## 📊 Dataset Information
This project uses publicly available datasets including:
- Global COVID-19 case data  
- Flight operations data  

The datasets were preprocessed to ensure:
- Removal of missing or inconsistent values  
- Standardized formats  
- Accurate and reliable analysis

## 🔎 Project Workflow

### 1️⃣ Data Cleaning & Preprocessing
- Handled missing values and duplicate records  
- Standardized column formats  
- Converted data types where required  
- Ensured overall dataset consistency  

### 2️⃣ Data Validation
- Verified data ranges and logical consistency  
- Identified anomalies and irregular patterns  
- Maintained high data integrity standards  

### 3️⃣ Exploratory Data Analysis (EDA)
- Compared flight activity before and during COVID  
- Analyzed trends in confirmed cases  
- Studied correlation between pandemic severity and flight reduction  

### 4️⃣ Data Visualization
- Created charts and graphs using Python libraries  
- Built an interactive dashboard using Power BI  
- Highlighted key patterns in flight decline and recovery

### Key Dashboard Features:

## 📈 Key Insights
- Significant decline in global flight operations during peak COVID waves  
- Strong negative relationship between rising COVID cases and flight frequency  
- Gradual recovery trend observed after easing of restrictions  
- Aviation industry showed phased stabilization over time
